# Changelog

All notable changes to this project will be documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project intends to use [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- GitHub Actions CI and release workflow.
- Repository contribution, security, conduct, Issue and PR templates.
- Release staging, checksum, Plugin install and uninstall scripts.

## [0.1.0] - Pending first public release

### Added

- Windows Tauri 2 transparent desktop companion.
- Pixel pet, DeepSeek balance orb and DSH chat modes.
- Tray menu, click-through controls and single-instance behavior.
- DSH Cordis Plugin process supervision.
- ACP v1 NDJSON initialization, persistent process and reusable session.
- Request-scoped native streaming events and turn cancellation.
- ACP session ID persistence, `session/resume` and reconnect fallback.
- Windows Credential Manager storage for DeepSeek API Key.
- Official DeepSeek `/user/balance` integration.
- Rust, TypeScript, Plugin, state reducer and native lifecycle tests.
